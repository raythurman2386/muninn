# Getting Started

Three habits make a vault useful:

1. Write a note when something is worth keeping.
2. Link it to a note you already have with `[[double brackets]]`.
3. Let the [[Backlinks]] accumulate. They become the map.

## Make a note

Press `⌘N`. The app creates a file named `Untitled.md` in the vault root and puts the caret in
the editor. Rename it in your file manager when the thought has a name.

## Link it

Type `[[` and a title. [[Wikilinks]] are resolved by filename, case-insensitively. `[[welcome]]`
and `[[Welcome]]` are the same note.

## Read it

The **Read** mode renders the Markdown. A link that points nowhere is drawn faintly: click it
and the note is created for you.
