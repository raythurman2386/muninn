# Welcome

This is a small vault for **Muninn**, a local-first Markdown notes app built with Rune.

It is a plain folder of Markdown files. Nothing is locked in a database: every note is a file
you can read, move or put in version control.

Start with [[Getting Started]], then follow the links into the [[Knowledge Graph]] and
[[Wikilinks]]. The graph view shows the same links as a map you can drag around.

> A vault is a conversation between notes. Links are the sentences.

## What is here

- [[Daily Notes]] — a light journaling habit
- [[Design Principles]] — how the app looks and feels
- [[Scratchpad]] — an island with no links, for testing the graph

Use `⌘K` (or Ctrl+K) to search, `⌘N` to make a note, and `⌘G` to open the graph.
