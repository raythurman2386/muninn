# Welcome

This is the tutorial vault for **Muninn**, a local-first Markdown notes app
built with Rune.

It is a plain folder of Markdown files. Nothing is locked in a database: every
note is a file you can read, move or put in version control.

Start with [[Getting Started]], then follow the links into [[Knowledge Graph]]
and [[Wikilinks]]. The graph view shows the same links as a map you can drag
around.

> A vault is a conversation between notes. Links are the sentences.

## What is here

- [[Getting Started]] — the first note, links and modes
- [[Markdown]] — blocks, code and task lists
- [[Wikilinks]] — links, aliases and headings
- [[Backlinks]] — the other half of a link
- [[Knowledge Graph]] and [[Local Graph]] — the whole map and one neighbourhood
- [[Boards and Kanban]] — the two visual modes
- [[Launch Week]] — a sample Kanban; open it and press `⌘5`
- [[Daily Notes]], [[Design Principles]], [[Typography]] and [[Scratchpad]]

Use `⌘K` (or `Ctrl+K`) to search, `⌘N` to make a note, `⌘I` to import a
document, `⌘G` to open the graph, and `⌘?` for every shortcut. Settings is
`⌘,`.
