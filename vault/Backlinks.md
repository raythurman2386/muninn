# Backlinks

A backlink is a link pointing *at* this note. It is the other half of [[Wikilinks]], and the
reason a vault gets more useful as it grows.

If you open [[Knowledge Graph]], this note appears in its links rail because of the link in the
sentence above. Nothing was registered; the index is rebuilt from the files each time.

## Context matters

A backlink without context is just a title. The rail shows the line that made the link, so a
note can say *why* it points here.

> Links are cheap to write and expensive to maintain by hand. Let the index do it.
