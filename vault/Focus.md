# Focus

Focus is a feature of the interface, not a setting. The graph dims everything outside the
selected note's neighbourhood so the eye has somewhere to land.

- **Write** mode has no chrome inside the page.
- **Read** mode centres the text measure.
- **Graph** mode dims distant nodes and keeps the camera still until you move it.

The same idea runs through [[Design Principles]] and [[Local Graph]].

> Make the next action obvious. Remove what is not the next action.
