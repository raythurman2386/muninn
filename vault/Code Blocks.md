# Code Blocks

Fenced blocks keep their brackets, so a note about syntax can show syntax without creating
links.

```toml
[dependencies]
muninn-core = { path = "crates/muninn-core" }
muninn-graph = { path = "crates/muninn-graph" }
```

Inline code is the same: `[[Welcome]]` is text, not a link.

If you want a real link next to an example, put it outside the tick marks: [[Markdown]].
