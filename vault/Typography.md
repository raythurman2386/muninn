# Typography

The body is Inter at 14 points on a 25-point line, in a measure that stops around 780 points.
Long lines are easy to write and hard to read; the editor and the preview share the same
measure so switching modes does not move the text.

## Hierarchy

- Note title: 13 points, medium, in the title bar.
- Section heading: from the Markdown style, one step up from the body.
- Body: 14 / 25.
- Caption: 11 / 16, for counts and hints.

## Rhythm

Spacing is a small set of steps, not a slider. The sidebar, the rail and the page all use the
same gap between a title and its explanation.
